Multi-Model AI Comparison Platform: Developed a scalable microservices-based application using Java, Spring Boot, Spring AI, Angular, PostgreSQL, Redis, API Gateway, and Eureka Service Registry. Integrated Gemini, Gemma, and Qwen AI models to enable side-by-side comparison of AI-generated responses through a single user request. Implemented support for text, voice, image, and document inputs, with asynchronous processing for improved performance. Designed RESTful APIs, chat history management, Redis caching, and service discovery to ensure high availability, low latency, and seamless communication across distributed services. Built a responsive Angular UI for real-time AI interaction and response visualization.
